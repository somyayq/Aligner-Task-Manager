# Aligner – Minimalist Team Task Manager

## Overview
Aligner is a sleek, high‑performance team task manager built with **Next.js 16**, Tailwind‑like utilities, and a focus on clean UI, dark mode, and premium design.

- **Modern UI** – glass‑morphism style, smooth micro‑animations, and a curated HSL color palette.
- **Features** – project creation, task boards, dashboards with metrics, role‑based security, and real‑time updates.
- **Tech Stack** – Next.js (app router), React, TypeScript, and a small set of UI components.

## Getting Started (Local)
```bash
# Clone the repo (if you haven't already)
git clone https://github.com/somyayq/Aligner-Task-Manager.git
cd Aligner-Task-Manager

# Install dependencies
npm install

# Run the development server
npm run dev   # http://localhost:3000
```

## Scripts
- `npm run dev` – Starts the Next.js development server.
- `npm run build` – Builds the production bundle.
- `npm start` – Starts the production server after a build.

## Deployment to Railway
1. Sign up / log in to [Railway](https://railway.app).
2. Click **New Project → Deploy from GitHub** and select the `Aligner-Task-Manager` repository.
3. Railway will auto‑detect a Next.js app. Verify the build command is `npm run build` and the start command is `npm start`.
4. Deploy. Railway provisions a live URL (e.g., `https://aligner-task-manager.up.railway.app`).
5. Add any environment variables if you add a DB later – none are required for the current version.
